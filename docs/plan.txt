THE SEED CHRONICLES — GAME ARCHITECTURE PLAN
================================================

------------------------------------------------
SHARED SYSTEMS / HELPERS
------------------------------------------------
- clearScreens() / showScreen() / showOverlay() — reused from Valentine's site
- addRestartBtn() — persistent "return to start" option on every screen
- Chapter transition system: fade/dissolve between biome color palettes
  (breeze motif — seed gets "blown" from one world to the next)
- Taunt/retry system: mini-games never dead-end, looping back with a
  snarky message (consistent with established teasing-but-safe pattern)
- Seed character evolves visually across chapters (leaf sprout -> sweaty ->
  singed -> scarred-but-determined)
- Tone flag per chapter: chaotic (default) vs sincere (Ch6, back half of Ch7,
  Credits) — controls whether taunt/joke text appears
